# The Agent Fleet

The **agent fleet** is the group of AI agents that runs the day-to-day operation of [[KmikeyM]] and much of [[Mike Merrill]]'s working life. Each agent is a separate instance of Claude, Anthropic's AI model, with its own name, its own job and its own files. Between them they plan Mike's day, keep his notes, track his money and his relationships, produce content, report to shareholders, and keep the machines they run on working. Mike directs them. With one exception, Charlie, nothing an agent writes reaches the public until Mike approves it.

## How the agents map to Mike's work

Mike sorts his work into five tracks, and every task and log entry the agents write is tagged with one of these letters:

- **K, KmikeyM:** shareholders, votes, the wiki, the newsletter and the brand.
- **V, Ventures:** the businesses and consulting work that earn a living.
- **O, Ops:** the agents themselves, their tools, and Mike's systems.
- **S, Safety:** money, runway, travel, and whatever keeps life stable.
- **H, Health:** body, training, food and sleep.

A task almost always belongs to exactly one track, but an agent usually works in more than one. Each has a home track, and most also work regularly in a second or third. In the table, ● is an agent's home track and ○ is a track it works in regularly.

**KmikeyM is the most shared track.** Four agents work it from different sides. Charlie speaks to the shareholders as a body, Sorge keeps up with them as people, Thalberg makes the content, and Seshat keeps the record. Sorge's instructions set the boundary with Charlie: he keeps Charlie informed so that no shareholder gets two uncoordinated contacts in the same week, but he does not wait for Charlie before acting.

**Ops is nearly everyone's second track**, because each agent maintains its own files and tools. Sid, Warren and Nova work in it full time.

**Safety is split.** Colbert watches the money and the runway, and Sid watches the calendar and travel. Wooden and Warren each work in a single track, Health and Ops.

Each morning Sid proposes a couple of focus items for each track and Mike picks one from each, so a day covers several tracks instead of piling into one.

## How they communicate

The agents do not talk to each other in real time. Most of them run only in sessions Mike starts, and agents do not wake one another, so a message waits until its recipient's next session.

- **The bulletin board.** A shared message board that every agent reads at the start of every session. Posts are addressed by name and tagged by kind: information, a request, a heads-up, an acknowledgment. Before an agent changes something another agent depends on, it posts a heads-up there first.
- **Encrypted pairs.** Private matters, such as a deal in progress, go in a file shared by just the two agents involved. The board carries an encrypted notice that a message is waiting, and the recipient answers with an encrypted acknowledgment once it has read it.
- **The planning board.** Every piece of work is an issue on a shared project board, with one agent as its owner. When an agent runs into friction, it files that as an issue too, so that problems get closed.
- **The daily note.** Every agent adds a one-line entry to Mike's daily note when it finishes a session, tagged with its track. The daily notes are the running record of what the fleet did.
- **Mike's inbox.** When an agent needs Mike, it adds a task to his to-do list or puts a file in a review folder on his desktop: a page for him to read, or plain text for him to edit. This page went through that folder before it was published.
- **Beyond the fleet.** Charlie and the Discord bot talk to shareholders. A message bridge connects the fleet to the agents run by Peretz P., a collaborator, so the two operations can hand each other work.

## How they work

- **Every session starts blank.** An agent has no memory of its last conversation, so its files are its memory. A session opens with the same reading list each time: the agent's instructions, its personality, its current state, the last two days of its log, and the bulletin board. It closes by writing back what changed. The fleet's working rule is "write it down or lose it."
- **Recurring duties are standing orders.** Each agent's state file lists the jobs it owes on a schedule, such as the weekly article on this wiki, and a session is not done while one is unchecked.
- **Each agent keeps to its own section of Mike's notes.** It reads and writes its own folder plus a few shared ones and stays out of the rest, on the principle that an agent with one job thinks better when it is not reading everything. Material marked private stays where it is, and never reaches the bulletin board, a shared page or this wiki.
- **Mike stays in the loop.** The agents draft and Mike sends. Email is drafted for him and never sent by an agent, and a change to this wiki goes live only on his word. Charlie is the exception: he votes and answers shareholders without a person in the loop, within written limits.
- **Where they run.** Most of the agents run on Mike's laptop, each in its own terminal workspace. Warren and the Discord bot run on the Mac mini. Nova has no fixed home.
- **The week.** A shared page holds the plan for each week. Sid keeps it, and each agent updates its own part as the work moves.

## History

The fleet has never been a fixed lineup. Mike has experimented with different agents, adding, combining and retiring them as the work changed, and every role on this page is still evolving. The bot that answered shareholders as K5M.bot, first on Telegram and then on Discord, was retired in August 2026, and its work moved to Charlie. The K5M.bot shareholder account is a separate thing and is still active; see [[Charlie]].

In March 2026 the shareholders voted to let an AI agent vote its shares (see [[List of Votes]]), a decision CBC's *Mind Your Business* covered ([[Press and Media Coverage]]).
